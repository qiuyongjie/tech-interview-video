# tech-interview-video v2.2

技术面试题讲解视频生成 Skill（动画版 / 图文结合 / 开场白 + 字幕 / 个人级与项目级通用）

## 版本状态

- v1.0 已在 CodeBuddy 环境验证通过（2026-11-23，静态翻页版）。
- v2.0 为迭代版本，新增：逐条渐入动画、灵活页数、独立结束语、
  风格档案化（风格不固定，须与主题强相关）。建议首次使用时复验。
- v2.1 新增图文结合：每个内容页必须含至少一个图形化
  元素（流程图/架构图/对比卡片/时序图/数据大字等，形状实际绘制），
  严禁纯文字堆砌；大纲阶段为每页设计图示方案，图示参与动画分层。
- v2.2 新增（当前版本）：① 独立开场白页（问候 + 主题引入 + 内容预告）；
  ② 视频默认烧录字幕，逐句校对确保准确无误、无错别字，
  同时输出 `subtitles.srt` 字幕文件。

## 功能简介

将任意技术主题（编程语言、框架、工具、数据库、云服务等）的面试题，
自动转化为四件交付物：

1. `outline.md` —— 页数按内容量灵活决定（开场白 + 每题 1–2 页 + 总结 +
   结束语，典型 6–16 页），联网核实并标注来源，含开场白文案、
   完整性自检结果、每页图示方案与呈现顺序标注
2. `slides.pptx` —— 图文结合（v2.1）：用 python-pptx 原生形状绘制
   流程图、架构框图、对比卡片、时序图、数据大字等，
   图示占页面视觉面积 ≥ 40%；风格与主题强相关
   （内置可爱风/深色科技风/商务风档案，可自定义），
   元素按呈现顺序分层命名，每页不超过 3 个要点
3. `subtitles.srt` —— 字幕文件（v2.2）：每条字幕对应一个分句、
   与配音/画面停留严格对齐；逐句校对后零错别字
4. `video.mp4` —— 1080p 逐条渐入动画视频：以开场白页开篇（问候 +
   主题引入 + 内容预告）；标题、要点、图示节点、代码逐元素依次显现
   （ffmpeg xfade 渐入 0.4–0.6s），配音与分句对齐，默认烧录校对后的
   字幕；结尾为独立结束语页（总结 + 收尾画面 + 淡出黑场）；
   TTS 不可用时降级为无配音 + 字幕版

## 核心机制

- 强制人工审核点：大纲必须经用户回复"确认"后才进入 PPT 与视频阶段，
  AI 严禁跳过或自行推断同意。
- 图文结合（v2.1）：每个内容页必须设计并绘制图示，"要点讲是什么，
  图示讲怎么流转"；图示节点独立命名参与动画。
- 开场白与字幕（v2.2）：视频以开场白页开篇；字幕与讲解文案逐字一致，
  交付前逐句校对，零错别字后才允许烧录。
- 元素分层命名（`L{层}_{名称}`）是动画管线的复用基础。
- 风格即配置：新增风格只需新增一张风格档案表。

## 依赖环境（实测于 Windows 11 + CodeBuddy）

- Python 3.9+（实测 3.11.8）
- python-pptx 1.0+：`pip install python-pptx`（含删形生成动画帧）
- Pillow：`pip install Pillow`（字幕降级方案）
- edge-tts：`pip install edge-tts`（配音，需联网）
- ffmpeg 9.x：下载构建包并加入 PATH（xfade 动画合成 + subtitles/libass 字幕烧录）
- 幻灯片导出 PNG：LibreOffice 或 PowerPoint/WPS COM（二选一）；
  COM 导出后注意结束占用进程再重写 pptx（详见 SKILL.md）

## 常见问题

- **Q：AI 跳过了"确认"环节直接生成 PPT？**
  A：在 SKILL.md 硬性规则区追加更强化措辞（"必须""严禁""绝对禁止"），
  并在审核点处重复声明；本 SKILL.md 已内置多层防护。
- **Q：视频元素不是逐条出现，而是整页展示？**
  A：检查 PPT 形状是否按 `L{层}_{名称}` 命名分层；未分层时阶段三会
  退化为静态整页。SKILL.md 阶段二"元素分层"为硬性要求。
- **Q：视频没有声音？**
  A：检查 edge-tts 与网络；不可用时 Skill 自动生成无配音 + 字幕版。
- **Q：视频没有字幕或字幕有错别字？**
  A：检查是否输出了 `subtitles.srt` 且是否执行逐句校对（SKILL.md 阶段三
  "字幕生成与校对"为硬性要求）；校对通过后才烧录字幕。
