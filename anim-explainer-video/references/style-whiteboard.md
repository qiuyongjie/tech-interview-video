# 风格模板：浅色白板手绘风

适用于"面向无技术背景观众"的通俗讲解。与默认深色科技风不同，整套色彩反转为米白纸面 + 深墨线条。

## 色板（写入 storyboard.json.style_tokens）

| 角色 | 值 |
|---|---|
| `bg` | `#F7F4EC` 米白纸面 |
| `surface` | `#FFFFFF` 白色卡片 |
| `text` | `#2B2B2B` 深墨正文 |
| `muted` | `#8A8578` 灰褐注释 |
| `entity` | `#2E5A88` 深蓝实体 |
| `focus` | `#D97706` 橙褐焦点 |
| `relation` | `#9A9588` 灰褐连线 |
| `good` | `#2E7D5B` 墨绿 |
| `bad` | `#C0392B` 砖红 |
| `assumption` | `#7C5CBF` 紫 |
| `quantity` | `#B45309` 金褐数字 |

## 运行时适配

- 背景扫描光与网格线改为暖灰 `rgba(120,110,90,0.045)`，不能在浅色底上出现亮色块。
- 字幕胶囊改用白色填充 + 细灰描边，保证在米白底上仍有边界。
- 代码面板使用 `#EFECE3` 浅灰底，扫光改为橙褐 `rgba(217,119,6,0.08)` 全高柔和渐变。
- 组件卡片保持白色填充 + 语义色描边，必要时加轻微圆角模拟白板卡片。

## 动效约束（与深色风一致）

- 装饰不得穿越文字、不得进入字幕安全区。
- 扫光不得出现可见矩形边界。
- 逐词高亮用文字下方的柔和底衬，不要重复绘制文字。
